## Featured project

### Excel Data Standardization & Validation Platform

A full-stack platform for transforming different asset spreadsheets into organization-standard Excel workbooks. It detects worksheet structures, normalizes data, supports automatic and manual column mapping, validates data quality, and allows corrections before export.

Highlights:

- Automatic worksheet detection and safe column mapping
- In-app data correction without changing the source file
- Versioned Excel templates with rollback support
- Validation for required fields, dates, numbers, statuses, and duplicates

Built with Next.js, React, TypeScript, Node.js, Python, ExcelJS, SheetJS, and openpyxl.

[View the source code](https://github.com/pgplagrob/excel-converter)
